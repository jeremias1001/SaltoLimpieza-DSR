# SaltoLimpieza · Digital Sales Room

Sales room interactivo para presentar la propuesta funcional del nuevo e-commerce de **SaltoLimpieza**.

## Qué muestra

- Visión general del e-commerce
- Catálogo y variantes de productos
- Gestión de inventario y stock
- Flujo de pedidos
- Clientes y segmentación
- Promociones y descuentos
- Pagos y despacho
- Escalabilidad futura

## Stack visual

- Tailwind CSS
- Alpine.js
- Chart.js
- Lucide Icons
- Plus Jakarta Sans + Manrope

## Despliegue en Vercel

1. Importar este repositorio en Vercel.
2. Framework Preset: **Other**.
3. No requiere Build Command.
4. No requiere Output Directory.
5. Deploy.

El proyecto es estático y no requiere instalación de dependencias ni variables de entorno.
