# SaltoLimpieza · Digital Sales Room

Sales room interactivo para que SaltoLimpieza experimente su futuro e-commerce antes de que esté construido: cómo lo administrará, qué verá su cliente al comprar y hasta dónde puede crecer.

## Qué muestra

- **Tu e-commerce** — visión general con acceso directo a los 3 mundos.
- **Tu administración** — dashboard, productos (con creación simulada), pedidos (con detalle y timeline), clientes, promociones, pagos y despachos, configuración.
- **Tu tienda** — inicio, catálogo con filtros, ficha de producto con variantes, carrito y checkout simulado de punta a punta.
- **Crecimiento** — integraciones agrupadas por estado (incluido / configurable / integrable / futuro) y roadmap por etapas.

Todas las interacciones (crear producto, crear promoción, abrir un pedido, agregar al carrito, avanzar el checkout) son simulaciones locales: no hay backend ni se procesan pagos reales, y el estado se reinicia al recargar la página.

## Despliegue en Vercel

1. Importar este repositorio en Vercel.
2. Framework Preset: **Other**.
3. No requiere Build Command.
4. No requiere Output Directory.
5. Deploy.

El proyecto es estático y no requiere instalación de dependencias ni variables de entorno.
